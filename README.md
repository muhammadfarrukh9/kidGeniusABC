# Kid Genius ABC

Expo React Native app for playful ABC learning. The screens mirror the provided concept: splash, onboarding, home, alphabet grid, letter details, tracing, phonics, flash cards, quizzes, mini games, rewards, progress, profile, settings, parent info, and exit/empty states.

## Setup

```bash
npm install
npm start
```

The app is currently powered by local demo content in `src/data/content.js`. Connect it to the backend API by replacing the local data reads with calls to the Node server in `../KidGeniusBE`.
